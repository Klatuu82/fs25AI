# fs25AI
Ein Modifikationstool für Farm Simulator 25 mit dem es möglich sein soll, KI innerhalb des Spiels zu benutzen, sei es Chat GPT oder irgendeine andere. Dafür werden diverse Daten aus dem Spiel ausgelesen und über ein Mod bereitgestellt für die KI eventuell auch ein KI Modell eingebunden. Genau, das steht noch nicht ganz fest.
